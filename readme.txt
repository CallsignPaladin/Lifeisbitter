Create: Life is bitter

Life is bitter is Create addon that forces players to use create machinery more to progress.

Adding languages is welcomed, same with bug reports.

Versioning:
This project uses format X.X.X.X. Following in decending order:
Major - self explanotary
Minor - adding or changing features
Patch - bug fixes, small adjustment
Side - client or server only changes

Thanks to that you don't need to always have the same version to connect to server, 
both server and client just need to share first three (X.X.X) nubmers of version.
